# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 26.4.x | Yes (latest feature release) |
| 26.3.x (LTS) | Yes, until 2028-10-28 |
| 26.2.x | Fixes only until 26.3.0 adoption; please upgrade |
| older | No |

## Reporting a vulnerability

Please do **not** open a public issue. Report privately to the maintainers (add a
contact address here before publishing), including the version, a description, and
steps or a proof of concept. Expect an acknowledgement, then a fix released as a
patch version on the LTS line.
